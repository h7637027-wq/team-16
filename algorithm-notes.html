TECHNICAL DOCUMENTATION

Algorithm notes & reproducibility

The first prototype uses a transparent deterministic rule-based engine. It does not claim to be a trained machine-learning model.

Knowledge-gap detection

Topics with estimated mastery below 60% are marked as gaps. Topic estimates are derived from a synthetic topic prior and, when history is available, quiz and coding evidence. Sparse data is shrunk toward a conservative prior; cold-start students receive a safe initial estimate.

Learning-path optimization

The engine greedily selects the highest-priority eligible topic. Priority is based on mastery deficit multiplied by topic importance, with a small focus-topic bonus. A topic can be selected only if its prerequisites are already mastered or have been selected earlier in the roadmap.

Adaptive quiz and AI explanation status

This first version delivers the recommendation engine and explainable rule-based rationale. A real question bank, answer submission/scoring flow, persistent student history, and LLM-generated explanations are planned implementation steps and must not be presented as completed until tested.

Baseline method

The baseline follows the catalog's fixed linear order; the adaptive method follows its recommended order. Both use the same synthetic mastery state and 30-minute study budget. The displayed improvement is a simulated estimate of average mastery points gained across nine topics, not an empirical result.

Time complexity

For V topics and E prerequisite edges: mastery and gap scan O(V); greedy path selection O(V² + E); prerequisite validation O(V + E); baseline simulation O(V). This prototype uses nine topics, so the path can be recalculated synchronously during an interactive demo.

Reproducibility

All five built-in scenarios use fixed synthetic values. Repeating a scenario returns the same mastery values and recommendation order. For a competition result, validate the method on a separate held-out dataset and report the dataset, metric, and test protocol.
